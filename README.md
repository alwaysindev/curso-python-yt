# 🐍 Curso de Python – Nivel Básico

Este repositorio contiene el material de un curso de **Python desde cero**, pensado para quienes quieren iniciarse en la programación.  
El contenido está organizado por carpetas, siguiendo una progresión de dificultad.

---

## 📂 Contenido del curso

**01_Basics**  
   - Introducción a Python  
   - Tipos de datos primitivos (`int`, `float`, `str`, `bool`)  
   - Operadores y primeras expresiones  

**02_Basics**  
   - Variables  
   - Conversión de tipos  
   - Entrada y salida con `input()` y `print()`  

**03_Condicionales_y_Bucles**  
   - Estructuras condicionales (`if`, `elif`, `else`)  
   - Bucles `for` y `while`  
   - Uso de `break` y `continue`  

**04_Listas_y_otros_objetos**  
   - Listas y tuplas  
   - Diccionarios y conjuntos  
   - Operaciones y métodos más comunes  

**05_Funciones**  
   - Definición y uso de funciones (`def`)  
   - Parámetros y valores de retorno  
   - Ámbito de variables  

**06_Control_de_errores**  
   - Introducción al manejo de excepciones  
   - Uso de `try`, `except`, `finally`  

**07_Manejo_de_Archivos**  
   - Lectura y escritura de archivos de texto  
   - Modos de apertura (`r`, `w`, `a`)  

**08_POO**  
   - Conceptos básicos de Programación Orientada a Objetos  
   - Clases y objetos  
   - Métodos y atributos  

---

## 🚀 Requisitos

- Python 3.x instalado en tu sistema  
- Un editor de texto o IDE (por ejemplo: [VS Code](https://code.visualstudio.com/), PyCharm, o incluso Jupyter Notebooks)  

---

## ▶️ Cómo usar este repo

1. Clona el repositorio:  
   git clone https://github.com/usuario/curso-python-basico.git

2. Entra en la carpeta del curso y navega por los temas:
  cd curso-python-basico/03_Condicionales_y_Bucles

3. Abre el notebook en Jupyter en tu editor de código favorito o en el propio jupyter:
  jupyter notebook 01_condicionales.ipynb

4. Ejecuta las celdas con Shift + Enter para probar los ejemplos.

## 🎯 Objetivo de aprendizaje

Al finalizar este curso serás capaz de:

- Escribir programas sencillos en Python.

- Manejar estructuras de datos básicas.

- Usar condicionales, bucles y funciones propias.

- Controlar errores y trabajar con archivos.

- Crear clases y objetos simples.
